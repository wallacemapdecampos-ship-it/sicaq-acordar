# sicaq-acordar

Só mantém o servidor do Assistente SICAQ acordado das 07h às 23h (Brasília),
visitando `https://assistente-sicaq.onrender.com/health` a cada 4 minutos.

Não tem código do sistema: é público para usar o GitHub Actions de graça.
Para pausar: Actions > "Manter servidor acordado" > Disable workflow.
